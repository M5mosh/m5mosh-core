# Review Checklist

## Before Review
- [ ] Understand the goal
- [ ] Read the challenge clearly
- [ ] Check requirements and acceptance criteria
- [ ] Review code or docs for completeness

## During Review
- [ ] Confirm correctness
- [ ] Check for missing documentation
- [ ] Check edge cases
- [ ] Identify security or privacy risks
- [ ] Validate tests or evidence

## After Review
- [ ] Request changes if needed
- [ ] Approve only with evidence
- [ ] Document final outcome
